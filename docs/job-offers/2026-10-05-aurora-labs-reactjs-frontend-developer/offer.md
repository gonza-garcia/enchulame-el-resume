## Job description

**About Aurora Labs**

Aurora Labs builds slot-booking and yard-management software for mid-size logistics
operators. The product team is fully remote across the Americas, with 18 engineers
working in two-week iterations.

**The role**

We are hiring a ReactJS Frontend Developer to join the operations console team. You
will work on the daily workflow of dispatchers: dense tables, live status updates and
forms that cannot lose data.

What you will do:

*   Build and maintain React features in our operations console with TypeScript.
*   Model client state with Context API where it fits and keep data fetching predictable.
*   Refactor large screens into small, testable components with SOLID and Clean Code
    practices.
*   Grow our shared component library and keep accessibility in every flow.
*   Write unit and integration tests with Vitest and review your teammates' pull
    requests.

What we look for:

*   3+ years building production React applications.
*   Strong TypeScript and modern React (hooks, context, composition).
*   Care for structure: SOLID, small modules, clear naming, readable diffs.
*   Testing habits beyond the happy path.
*   Advanced English for daily communication with US-based customers.

Nice to have:

*   React Query or similar data-fetching libraries.
*   Design system work shared across teams.
*   Experience with logistics, dispatch or operations software.

## Our hiring process

1.  Intro call with recruiting.
2.  Technical interview with the console team (practical discussion, no trick puzzles).
3.  Paid take-home review and a short culture conversation.
